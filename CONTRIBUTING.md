# Contributing to zxing-cpp

Thanks for your interest in contributing! Bug reports, test images, documentation, and pull requests are all welcome. For larger changes (new symbologies, API changes), please open an issue first to discuss the approach.

## Licensing

zxing-cpp is licensed under the Apache License 2.0. By submitting a contribution, you confirm that you have the right to submit it and that it may be distributed under that license.

## Pull requests

- Explain the motivation and approach in the description.
- Keep changes focused and follow the existing code style.
- Add or update tests, and make sure the test suite passes.

## What we can't accept

To protect the project and its users, we won't accept code or data that:

- was derived from reverse engineering proprietary software (decompiling, disassembling, or similar analysis),
- comes from leaked or otherwise improperly obtained sources,
- has unclear provenance, meaning you can't say where the technical information came from, or
- is copied from projects with incompatible licenses.

Maintainers may close contributions with unclear provenance without a detailed review, and may ask the hosting platform to remove problematic content. This is a precaution and not a judgment of the contributor.

## AI-assisted contributions

You are responsible for everything you submit, whether or not an AI tool helped write it. Please mention substantial AI assistance in the pull request and never give AI tools proprietary binaries or confidential material to analyze.
